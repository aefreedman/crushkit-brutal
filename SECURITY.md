# Security

Please do not disclose suspected vulnerabilities in a public issue or pull request. Use this repository's **Security → Report a vulnerability** feature to contact the maintainer privately. If that feature is unavailable, ask the maintainer for a private contact channel without including vulnerability details.

The latest `main` source is the current maintenance target; prereleases have no long-term support guarantee. Updates and reports are handled on a best-effort basis. Do not upload credentials, private project material or unrelated machine logs.
